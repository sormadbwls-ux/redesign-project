## ⚙️ 2. 리디자인 접근 프로세스

기존 공공 웹사이트 형태의 복잡한 메인 화면을 사용자 행동 순서(여정)에 맞춰 구조화했습니다.

```mermaid
flowchart LR
    A[기존 구조 분석] --> B[메인 노선 조회 UI 집중]
    B --> C[부가 서비스 그리드 정렬]
    C --> D[콘텐츠 영역 시각화 가공]
```

## 🧠 3. 정보 구조 및 화면 구성 (IA Map)

유저가 터미널 사이트에 접속하는 본질적인 목적인 '예매'를 최상단에 두고, 쇼핑/먹거리/교통 정보를 하단에 정돈한 레이아웃 구조입니다.

```mermaid
mindmap
  root((메인 레이아웃))
    최상단 GNB
      로고 및 대메뉴
      다국어 지원 인덱스
    핵심 기능 Hero
      출발지 도착지 선택 UI
      가는날 달력 및 실시간 운행상황
      버스 승차권 조회 버튼
    부가 서비스 연계
      제로데이 고속배송 택배 안내
      쇼핑 먹거리 볼거리 카테고리
    콘텐츠 플레이스 Footer
      버락 투어 콘텐츠
      하단 푸터 및 고객 센터 정보
```

## 📂 4. 주요 리디자인 설계 포인트


| 영역 | 세부 설계 내용 및 포인트 | 활용 툴 |
|---|---|---|
| **노선 및 승차권 조회** | 출발/도착지 선택 및 실시간 운행 상황을 한눈에 볼 수 있는 격자형 위젯 UI 컴포넌트 설계 | Figma |
| **제로데이 택배 배너** | 정보 인지도를 높이기 위해 집앞 픽업 등의 핵심 문구를 아이콘 태그와 함께 비주얼 배너로 시각화 | Photoshop, Figma |
| **버-락(bus-樂) 콘텐츠** | 터미널 야경 비주얼 소스를 배경으로 활용하여 '서울의 즐거움'을 전달하는 스토리텔링 레이아웃 구축 | Photoshop, Figma |

## 💡 5. Project Reflection (성장 회고)

이 프로젝트는 UI/UX 디자이너로서 웹 인터페이스를 정밀하게 분석하고 구조화해 본 **소중한 첫 번째 중심축**입니다.

* **그리드 기반 레이아웃 학습**: 흩어져 있던 대량의 텍스트와 교통 정보 데이터들을 마크업 구조를 고려하여 시각적으로 균형감 있게 정렬하는 감각을 다질 수 있었습니다.
* **디자인 컴포넌트의 이해**: 조회 위젯, 배너 카드, 콘텐츠 리스트의 최소 단위를 직접 기획하고 쪼개보며 디자인 시스템의 필요성을 깊이 깨달았습니다.
* **성장의 발판**: 본 프로젝트를 통해 배운 데이터 시각화와 컴포넌트 설계의 기초를 발판 삼아, 차기 프로젝트(`요리조리`)에서 **더 고도화된 디자인 시스템과 차별화된 UI 경험**을 완성해내는 핵심 원동력이 되었습니다.
